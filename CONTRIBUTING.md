# Contributing

Thanks for taking the time to contribute! 🎉 This project welcomes
contributions of all kinds — bug reports, fixes, documentation, and ideas.

## Ways to help

- **Report a bug** — open an issue describing what happened, what you
  expected, and how to reproduce it.
- **Suggest an idea** — open an issue and tell us what you'd like to see.
- **Send a change** — fix a bug, improve the docs, or add a feature.

## Making a change

1. Fork the repository and create a branch for your work.
2. Make your change, keeping it focused and easy to review.
3. Write a clear commit message explaining the *why*, not just the *what*.
4. Open a pull request describing your change and linking any related issue.

## A few friendly guidelines

- Keep pull requests small and focused — it makes review faster for everyone.
- Match the existing style of the surrounding code and docs.
- Be kind and respectful in discussions. We're all here to build something good.

Not sure about something? Open an issue and ask — we're happy to help. 💬
